# Cédrai — The Hidden Archive

호그와트의 네 기숙사에서 영감을 받은 Cédrai의 정적 포트폴리오입니다. 방문자는 슬리데린, 그리핀도르, 래번클로, 후플푸프 중 하나를 고를 수 있습니다. 선택은 브라우저의 `localStorage`에 저장되어 다음 방문과 글 읽기 화면에도 적용됩니다. 입장 버튼을 누르면 목차가 열리고, 한 번에 하나의 장을 볼 수 있습니다. 원본 포트폴리오의 소개, 활동, 공개 블로그 글, 일정, NOW, 연락처 구조를 간결하게 재구성했습니다.

## 실행

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. GitHub Pages는 저장소 루트의 `index.html`을 바로 서빙합니다. 빌드 과정은 없습니다.

## 콘텐츠

- `content.json`: 원본 저장소의 공개 블로그 목록, 일정, NOW 기록을 복사한 정적 데이터
- `posts.json`: 원본 공개 글 37개의 본문 (스크립트와 위험한 속성을 제거한 정적 데이터)
- `blog.html`, `blog.js`: 새 글 읽기 화면과 이전·다음 글 이동
- `index.html`: 페이지 구조와 링크
- `style.css`: 기본 디자인과 반응형 화면
- `houses.css`, `houses.js`: 네 기숙사 색상, 문장식, 선택기, 브라우저별 설정 저장
- `app.js`: 검색, 필터, 달력, 주문 메뉴

관리자 로그인, 글 작성, 일정 편집 등 서버 기능은 포함하지 않습니다. 활동 카드는 원본 사이트로 연결됩니다. 공개 블로그 글은 새 사이트 안에서 읽을 수 있으며, 이미지는 원본 사이트의 공개 이미지 주소를 사용합니다.
